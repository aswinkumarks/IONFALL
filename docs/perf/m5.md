# M5: dedicated server soak (16 test clients)

2026-10-22, build 92f227b+ (M5 work in progress), exported **Linux release
server** (`ionfall_server.sh`), Meridian Station, FFA, 16 headless test
clients (`--test-clients 16 --map station`, WanderInput, full client stack:
prediction, reconciliation, acks) in one process on the same machine.
Laptop: Intel Core i5-1135G7 (4 cores / 8 threads), Ubuntu 22.04.

**Note on the one bad window:** the 10.77 ms p99 and all 89 view-tick
anomalies fall in the same minute (8–9 min in), while other jobs (store art
rendering, test runs) were briefly using the same laptop. View-tick
validation clamped the late claims as designed; the other 59 windows had
p99 ≤ 5.9 ms and no anomalies.

**Note on p50:** the 2 ms p50 budget is for the reference 4-core desktop
CPU. This laptop also ran the 16 clients' full prediction stacks in the
same machine; p50 2.1–2.6 ms with all clients on the same CPU is within
reach of the budget, and the p99 budget holds. A desktop server without the
clients on it is expected to be lower.
